# Code of Conduct

Participation in the Fabric-Folia project is expected to be professional and respectful.

Contributors must:
- Discuss technical disagreements without personal attacks or harassment.
- Provide actionable, evidence-based feedback.
- Respect privacy and avoid publishing private logs, credentials, or player information.
- Keep reviews focused on the change and its technical consequences.

Maintainers may close contributions or discussions that violate these expectations. Reports can be sent privately through GitHub Security Advisories when they involve sensitive information.
