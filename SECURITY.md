# Security policy

Fabric-Folia is experimental and is not currently certified for production servers.

Report security-sensitive defects through [GitHub Security Advisories](https://github.com/PalorderSoftWorksOfficial/fabric-folia/security/advisories/new). Include the affected commit, Minecraft/Loader/Java versions, a concise impact description, and a minimal reproduction when safe to share.

Do not include server credentials, access tokens, private player data, or production world files in public issues. If a public report already contains secrets, rotate them and remove the sensitive material from the report.
